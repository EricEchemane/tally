## Question

Write the page Testers follow to install and run Tally on their own Mac.

- Requirements up front: a Mac, Homebrew, internet for the first setup only. Check the real minimums (macOS version, RAM: it was measured on an 8GB M1) against `setup.sh` and the M1 measurement.
- Steps: clone the public repo, `./setup.sh`, `./dev.sh`, open http://localhost:3000, scan the QR with a phone on the same Wi-Fi.
- Windows: say plainly it runs only a sample mode, and send visitors to the interactive sample review instead.
- Ends with a link to the Tester feedback form.
