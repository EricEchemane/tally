# Tester feedback form

Type: task (AFK)
Status: open

## Question

Build the Tester feedback form on the site and link it from the app.

- Fields: what worked, what broke, which receipt confused it, optional email (with consent if given).
- Saved in the same database as Early Access Requests, kept apart from them, and emailed to the team.
- Add a "Send feedback" link in the `web/` footer that opens the form. It is the only change to the app, and the only network link in it: opening it is the Tester's choice.
