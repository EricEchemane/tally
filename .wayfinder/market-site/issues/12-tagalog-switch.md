# Tagalog switch

Type: task (HITL for the copy)
Status: open
Blocked by: 05, 08, 09, 11

## Question

Add an English/Tagalog switch to the site, with English as the default and the choice remembered in the browser (no cookie).

- All visible copy comes from one English and one Tagalog source, so a missing translation falls back to English.
- BIR and glossary terms stay in English inside the Tagalog copy (Invoice, Official Receipt, TIN, Finding, Amount to Return).
- HITL: the user writes or checks every Tagalog string; no machine translation is shipped.
